# Mundo 7 — Reino dos Templos

Atlas de texturas 3D em mármore claro para as dez fases do sétimo mundo do Bombardeiro.

- **Arquivo:** `temple_marble_themes.svg`
- **Dimensões:** 384 × 960 px; grade 4 × 10; células de 96 × 96 px.
- **Colunas:** piso, piso ornamental, bloco indestrutível e bloco destrutível.
- **Paletas:** Carrara Clássico, Calacatta Dourado, Statuario Prateado, Rosa Imperial Claro, Jade Branco, Azul Nuvem, Lilás Celestial, Marfim Pérola, Champagne Cristal, Opala Boreal.
- **Acabamento:** mármore predominantemente branco, veios naturais, brilho polido, chanfros, relevos, sombras e bordas iluminadas.

Este atlas é um recurso visual isolado para inspeção e aprovação. Ainda não altera a seleção de mundos, mapas, fases ou sistemas do jogo.
