# Recursos do Bombardeiro\n\nEsta pasta guarda recursos externos ao HTML. O APK empacota este diretório e sincroniza os arquivos para o armazenamento privado do aplicativo na primeira abertura e nas atualizações.\n\n- audio/: efeitos sonoros\n- images/: imagens de interface e cenários\n- sprites/: spritesheets de personagens e inimigos\n- maps/: dados de mapas e fases\n- music/: trilhas musicais\n\nO HTML usa caminhos relativos, como `game-assets/audio/explosion.wav`. Destino privado: `/data/user/0/com.bombardeiro.game/files/bombardeiro-game/`. O manifesto SHA-256 é gerado na compilação; o aplicativo copia somente arquivos novos ou alterados e remove arquivos antigos do pacote oficial.\n
